Keysight (Agilent) N934X Series Instrument Driver Readme

To rate this instrument driver, go to the driver download page on the Instrument Driver Network.

1. Overview

Instrument Driver Technology: LabVIEW Plug and Play (project-style)
Manufacturer: Keysight Technologies (Agilent Technologies)
Supported Language(s): LabVIEW
Supported Model(s): N9342C, N9343C, N9344C, N9321C, N9322C, N9323C, N9324C
Model(s) Tested: N9342C, N9322C, N9324C
Interface(s): USB, Ethernet, GPIB (N9321C/22C/23C/24C)
Firmware Revision(s) Tested: A.03.06 (N9342C), A.04.28 (N9322C)

Certified: Yes
NI Supported: Yes
Source Code Available: Yes

Driver Revision: 1.3
Original Release Date: 04/10/2012
Current Revision Date: 09/17/2025

2. Required Software

Some software components need to be installed before using this instrument driver. The minimum versions of these components are listed below, and can be downloaded from the Download Site.

VISA 5.0 or later

Refer to the LabVIEW Help for more information about software requirements. You access the LabVIEW Help by selecting Help»Search the LabVIEW Help.

GPIB Interface is only available for N932X models.

3. Known Issues

To report issues or provide feedback about this instrument driver, please contact technical support. The manual misses Valid Range information of controls in the following VIs, in which are marked as N/A:
Configure Limit Line.vi
Configure Marker Peak Search.vi
Configure Marker.vi
Configure Frequency (Center Span).vi
Configure Frequency (Start Stop).vi

agn934xni_ReadCurrentLimitsResult

ViStatus agn934xni_ReadCurrentLimitsResult (ViSession instrumentHandle, ViChar _VI_FAR limitLine[], ViPInt32 limitResult);

Purpose

Reads the result of limit line or limit in reflection measurement.
Note:
This function is valid in all models.

Parameters

Input
Name Type Description
instrumentHandle ViSession The ViSession handle that you obtain from the agn934xni_init or agn934xni_InitWithOptions function.  The handle identifies a particular instrument session.
Default Value: None
limitLine ViChar[] Specifies the limit line.
Valid Values: "1", "2"
Default Value: "1"
Output
Name Type Description
limitResult ViInt32 (passed by reference) Returns the result of limit line or limit in reflection measurement.
Command:
:CALCulate:LLINe[1]|2:FAIL?

Return Value

Name Type Description
status ViStatus Returns the status code of this operation.  The status code  either indicates success or describes an error or warning condition.  You examine the status code from each call to an instrument driver function to determine if an error occurred.
To obtain a text description of the status code, call the agn934xni_error_message function.  To obtain additional information about the error condition, call the agn934xni_GetError function.  To clear the error information from the driver, call the agn934xni_ClearError function.
The general meaning of the status code is as follows:
Value                  Meaning
-------------------------------
0                      Success
Positive Values        Warnings
Negative Values        Errors
This driver defines the following status codes:
Status    Description
-------------------------------------------------
WARNINGS:
3FFA2001  The instrument was in an uncalibrated state
when the measurement was taken.
3FFA2002  The measurement taken was over the instrument's
range.
ERRORS:
BFFA2001  The Active Marker is not enabled.
BFFA2002  The Active Marker is not a delta marker.
BFFA2003  The maximum waiting time for this operation was
exceeded.

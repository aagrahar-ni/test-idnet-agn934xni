agn934xni_ConfigureDemodulationLimit

ViStatus agn934xni_ConfigureDemodulationLimit (ViSession instrumentHandle, ViBoolean enableLimit, ViReal64 carrierPowerUpperLimit, ViReal64 depthFreqDeviationUpLimit, ViReal64 depthFreqDeviationLowLimit, ViReal64 carrierFrequencyOffsetUpper);

Purpose

Configures the Limit State, Carrier Power Upper Limit, Depth Upper/Lower Limit, Frequency Deviation Upper/Lower Limit, Carrier Frequency Offset Upper Limit for demodulation analysis.
Note:
This function is applicable for N9321C, N9322C, N9323C and N9324C models.

Parameters

Input
Name Type Description
instrumentHandle ViSession The ViSession handle that you obtain from the agn934xni_init or agn934xni_InitWithOptions function.  The handle identifies a particular instrument session.
Default Value: None
enableLimit ViBoolean Enables or disables the limit in demodulation analysis.
The driver uses this value to set the AGN934XNI_ATTR_AM_FM_LIMIT_STATE or AGN934XNI_ATTR_ASK_FSK_LIMIT_STATE attribute.
Valid Values:
VI_TRUE: Enable
VI_FALSE: Disable
Default Value: VI_FALSE
Commands:
:CALCulate:AMA:LIMit OFF|ON
:CALCulate:DMA:LIMit OFF|ON
carrierPowerUpperLimit ViReal64 Sets the upper limit of carrier power.
The driver uses this value to set the AGN934XNI_ATTR_AM_FM_CARRIER_POWER_UPPER_LIMIT or AGN934XNI_ATTR_ASK_FSK_CARRIER_POWER_UPPER_LIMIT attribute.
Valid Range:
Min:-100 dBm
Max: 30 dBm
Default Value: 0
Commands:
:CALCulate:AMA:LIMit:POWer:UPPer <value>
:CALCulate:DMA:LIMit:POWer:UPPer <value>
depthFreqDeviationUpLimit ViReal64 Sets the upper limit of AM/ASK depth or FM/FSK Frequency Deviation.
The driver uses this value to set the AGN934XNI_ATTR_AM_DEPTH_UPPER_LIMIT, AGN934XNI_ATTR_ASK_DEPTH_UPPER_LIMIT, AGN934XNI_ATTR_FM_FREQUENCY_DEVIATION_UPPER_LIMIT or AGN934XNI_ATTR_FSK_FREQUENCY_DEVIATION_UPPER_LIMIT attribute.
Valid Range:
AM/ASK:
Min: 0.1 %
Max: 100 %
FM/FSK:
Min: 1 Hz
Max: 5E+05 Hz
Default Value: 100
Commands:
:CALCulate:AM:LIMit:MDEPth:UPPer <value>
:CALCulate:ASK:LIMit:AMDepth:UPPer <value>
:CALCulate:FM:LIMit:FDUL:UPPer <freq>
:CALCulate:FSK:LIMit:FDUL:UPPer <freq>
depthFreqDeviationLowLimit ViReal64 Sets the lower limit of AM/ASK depth or FM/FSK Frequency Deviation.
The driver uses this value to set the AGN934XNI_ATTR_AM_DEPTH_LOWER_LIMIT, AGN934XNI_ATTR_ASK_DEPTH_LOWER_LIMIT, AGN934XNI_ATTR_FM_FREQUENCY_DEVIATION_LOWER_LIMIT or AGN934XNI_ATTR_FSK_FREQUENCY_DEVIATION_LOWER_LIMIT attribute.
Valid Range:
AM/ASK:
Min: 0.1 %
Max: 100 %
FM/FSK:
Min: 1 Hz
Max: 5E+05 Hz
Default Value: 100
Commands:
:CALCulate:AM:LIMit:MDEPth:LOWer <value>
:CALCulate:ASK:LIMit:AMDepth:LOWer <value>
:CALCulate:FM:LIMit:FDUL:LOWer <freq>
:CALCulate:FSK:LIMit:FDUL:LOWer <freq>
carrierFrequencyOffsetUpper ViReal64 Specify carrier frequency offset upper limit of demodulation analysis.
The driver uses this value to set the ASK_FSK_CARRIER_FREQUENCY_OFFSET_UPPER_LIMIT or AGN934XNI_ATTR_FM_FSK_CARRIER_POWER_UPPER_LIMIT attribute.
Valid Range:
AM/FM:
Min: -1e6 Hz
Max: +1e6 Hz
ASK/FSK:
Min: -2e6
Max: 2e6
Default Value: 10000
Command:
:CALCulate:AMA:LIMit:FOFFset:UPPer <freq>
:CALCulate:DMA:LIMit:FOFFset:UPPer <freq>

Return Value

Name Type Description
status ViStatus Returns the status code of this operation.  The status code  either indicates success or describes an error or warning condition.  You examine the status code from each call to an instrument driver function to determine if an error occurred.
To obtain a text description of the status code, call the agn934xni_error_message function.  To obtain additional information about the error condition, call the agn934xni_GetError function.  To clear the error information from the driver, call the agn934xni_ClearError function.

Value                  Meaning
-------------------------------

Positive Values        Warnings
Negative Values        Errors

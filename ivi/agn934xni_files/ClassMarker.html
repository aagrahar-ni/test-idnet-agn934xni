Marker

Most analyzers utilize markers.  The marker extension group defines extensions for analyzers capable of performing various functions on one or more traces that involve using markers.  Markers can be used for things as simple as getting amplitude value at a specific point to complex functions such as signal tracking.  The marker extension group defines additional attributes such Active Marker and Marker Amplitude.
